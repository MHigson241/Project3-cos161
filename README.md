#To-Do List System
Written by Madeline Higson and Iris McCain
A task managment/to-do list system written in Java for COS-161 at USM

#Installation:
*Ensure that Java Development Kit and Java Runtime Environment are installed on your PC
*Open your prefered command line interface (Command Prompt, Powershell, Terminal, etc)
*Navigate to the directory containing UserInterface.java
*Run "javac UserInterface.java" to compile the program
*Finally, run "java UserInterface" and that should run the program

#Usage:
When at the main menu, enter numbers/words/sentences into the command line when prompted
to tell the program what actions to take and input information like task names/descriptions.
When you are finished you can enter "10" at the main menu to close the program.
